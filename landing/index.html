Common questions

Titan AI uses HistGradientBoostingRegressor (scikit-learn) — a gradient boosting ensemble optimized for mixed-type features. Model v2.0 achieves 91% accuracy with MAE 121.1 and RMSE 171.2, trained on 158 samples with 5 engineered features: week, month, year, lag_1, and lag_4.

Under 5 minutes with Docker Compose. Upload your CSV, the ETL pipeline processes it, and the ML pipeline trains automatically. First forecasts appear within 30 seconds of training completion. No data engineering team required.

Any CSV format works. The ETL engine auto-detects date columns, demand/quantity columns, and product identifiers. The schema mapping UI lets you confirm column assignments before processing. No transformation needed before upload.

Yes. Every database record is scoped by organization_id. All queries, model versions, forecasts, inventory, and alerts are isolated per org at the query level — cross-org access is architecturally impossible even with a valid JWT token from another org.

Absolutely. Titan AI is fully containerized with Docker Compose. It runs on any infrastructure — AWS, GCP, Azure, or bare metal. The entire stack is self-contained with no external cloud dependencies. Enterprise plans include production deployment guides.

Z-score analysis compares actual demand against historical baselines and ML predictions. Deviations are classified by severity (low/medium/high/critical), flagged automatically, and pushed via WebSocket to connected dashboards in real-time.
